# Tópico 1 - Preparação do ambiente Linux

## Ambiente utilizado
VirtualBox com Ubuntu Server

## Comandos executados
- uname -a — mostra a versão do kernel
- whoami — mostra o utilizador atual
- hostname — mostra o nome da máquina
- pwd — mostra o diretório atual
- df -h — espaço em disco
- free -h — memória RAM
- mkdir — para criar diretorios
- tree — para listar diretorios

## Diferença entre VM, VPS e cloud
VM local: corre no teu computador, sem acesso externo
VPS: servidor alugado num datacenter, sempre ligado, tem IP público
Cloud: plataformas como AWS/Azure, escalam automaticamente, pagas pelo uso

## Dificuldades encontradas
Em termos de execução de comandos não tive muita dificuldade.
