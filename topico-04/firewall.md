# Firewall

## Estado inicial
O UFW estava inativo no início da atividade.


## Comando usado
Sudo ufw status verbose
 Resultado: inactive

## Interpretação:
O firewall ainda não estava a aplicar regras de filtragem.
Antes de ativar o UFW, é necessário garantir que as portas essenciais ficam permitidas, como SSH se houver acesso remoto e HTTP para o site publicado.
